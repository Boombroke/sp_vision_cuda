# YOLO 推理流程详解

## 整体流程图

```
用户调用 infer->forward(image) 
    ↓
1. 初始化阶段 (load)
    - 加载 TensorRT engine 文件
    - 解析输入/输出维度
    - 设置归一化方式、类别数等
    ↓
2. 预处理阶段 (preprocess)
    - 计算仿射变换矩阵 (原图 → 网络输入尺寸)
    - 图像数据拷贝到 GPU
    - 执行仿射变换 + 归一化
    ↓
3. TensorRT 前向推理 (trt_->forward)
    - 输入: 预处理后的图像 [N, 3, H, W]
    - 输出: bbox head 特征图 [N, num_anchors, output_dim]
    ↓
4. 后处理阶段 (decode_kernel_invoker)
    - GPU 上并行解码所有候选框
    - 坐标从网络输入尺寸映射回原图
    - 执行 NMS 去重
    ↓
5. 结果解析 (CPU 侧)
    - 从 GPU 拷贝结果到 CPU
    - 解析为 BoxArray 结构
    - 可选: 解码分割 mask (V8Seg)
    ↓
返回 BoxArray
```

## 详细步骤说明

### 步骤 1: 加载 Engine (`InferImpl::load`)

**位置**: `yolo.cu:560-611`

**作用**: 初始化推理器，解析模型配置

```cpp
bool load(const string& engine_file, Type type, 
          float confidence_threshold, float nms_threshold)
{
    // 1. 加载 TensorRT engine
    trt_ = trt::load(engine_file);
    
    // 2. 解析输入维度: [batch, 3, height, width]
    auto input_dim = trt_->static_dims(0);
    network_input_width_ = input_dim[3];   // 例如 640
    network_input_height_ = input_dim[2];  // 例如 640
    
    // 3. 解析输出维度: bbox head
    bbox_head_dims_ = trt_->static_dims(1);
    // 例如 [batch, 8400, 84] (YOLOv8: 8400个anchor, 84=4+80类)
    
    // 4. 根据模型类型计算类别数
    if (type == Type::V8) {
        num_classes_ = bbox_head_dims_[2] - 4;  // 84 - 4 = 80类
    } else if (type == Type::V5) {
        num_classes_ = bbox_head_dims_[2] - 5;  // 85 - 5 = 80类
    }
    
    // 5. 设置归一化方式
    normalize_ = Norm::alpha_beta(1/255.0f, 0.0f, ChannelType::SwapRB);
}
```

**关键信息**:
- `network_input_width/height`: 网络输入尺寸 (如 640x640)
- `num_classes_`: 类别数量 (如 COCO 80类)
- `bbox_head_dims_`: bbox 输出维度 `[batch, num_anchors, output_dim]`

### 步骤 2: 预处理 (`InferImpl::preprocess`)

**位置**: `yolo.cu:514-557`

**作用**: 将原图缩放到网络输入尺寸，并归一化

```cpp
void preprocess(int ibatch, const Image& image, ...)
{
    // 1. 计算仿射变换矩阵
    // 原图尺寸 → 网络输入尺寸 (保持长宽比，居中填充)
    AffineMatrix affine;
    affine.compute(
        make_tuple(image.width, image.height),      // 原图: 1920x1080
        make_tuple(network_input_width_, network_input_height_)  // 网络: 640x640
    );
    // affine.i2d: 原图 → 网络输入
    // affine.d2i: 网络输入 → 原图 (用于后处理还原坐标)
    
    // 2. 分配 GPU 内存
    float* input_device = input_buffer_.gpu() + ibatch * input_numel;
    
    // 3. 拷贝图像到 GPU (异步)
    cudaMemcpyAsync(image_device, image_host, size_image, 
                    cudaMemcpyHostToDevice, stream);
    
    // 4. 执行仿射变换 + 归一化
    warp_affine_bilinear_and_normalize_plane(
        image_device,           // 原图 (GPU)
        image.width * 3,        // 原图宽度步长
        image.width, image.height,
        input_device,           // 输出: 网络输入尺寸 (GPU)
        network_input_width_, network_input_height_,
        affine_matrix_device,   // 仿射矩阵
        114,                    // 填充值 (灰色)
        normalize_,             // 归一化: /255, BGR→RGB
        stream
    );
}
```

**关键点**:
- **仿射变换**: 保持长宽比缩放，不足部分用灰色(114)填充
- **归一化**: 像素值从 `[0,255]` → `[0,1]`，并 BGR→RGB
- **输出**: `input_buffer_` 中存储的是 `[batch, 3, 640, 640]` 的 float 数据

### 步骤 3: TensorRT 前向推理 (`trt_->forward`)

**位置**: `yolo.cu:683-687`

**作用**: 调用 TensorRT 执行神经网络前向计算

```cpp
// 组织 bindings (输入/输出指针)
vector<void*> bindings{
    input_buffer_.gpu(),        // 输入: [batch, 3, 640, 640]
    bbox_predict_.gpu()         // 输出: [batch, 8400, 84]
};

// 执行推理
if (!trt_->forward(bindings, stream)) {
    return {};
}
```

**输入**: 
- `input_buffer_`: `[batch, 3, 640, 640]` float 数组

**输出**:
- `bbox_predict_`: `[batch, num_anchors, output_dim]` float 数组
  - 例如 YOLOv8: `[batch, 8400, 84]`
  - 每个 anchor 的 84 维: `[cx, cy, w, h, cls0, cls1, ..., cls79]`

### 步骤 4: 后处理 - Bbox 解码 (`decode_kernel_common`)

**位置**: `yolo.cu:34-97`

**作用**: 在 GPU 上并行解码所有候选框，过滤低置信度，坐标映射回原图

```cpp
__global__ void decode_kernel_common(...)
{
    // 1. 每个线程处理一个 anchor
    int position = blockDim.x * blockIdx.x + threadIdx.x;
    float* pitem = predict + output_cdim * position;
    
    // 2. 读取预测值
    // YOLOv5/V3/V7 格式: [cx, cy, w, h, obj, cls0, cls1, ...]
    float cx = pitem[0];
    float cy = pitem[1];
    float width = pitem[2];
    float height = pitem[3];
    float objectness = pitem[4];  // 目标存在概率
    
    // 3. 过滤低 objectness
    if (objectness < confidence_threshold) return;
    
    // 4. 找最大类别得分
    float* class_confidence = pitem + 5;
    float confidence = *class_confidence++;
    int label = 0;
    for (int i = 1; i < num_classes; ++i) {
        if (class_confidence[i] > confidence) {
            confidence = class_confidence[i];
            label = i;
        }
    }
    
    // 5. 最终置信度 = obj * 类别置信度
    confidence *= objectness;
    if (confidence < confidence_threshold) return;
    
    // 6. 中心点+宽高 → 左上/右下角 (网络输入坐标系)
    float left = cx - width * 0.5f;
    float top = cy - height * 0.5f;
    float right = cx + width * 0.5f;
    float bottom = cy + height * 0.5f;
    
    // 7. 坐标映射回原图 (使用 d2i 逆变换矩阵)
    affine_project(invert_affine_matrix, left, top, &left, &top);
    affine_project(invert_affine_matrix, right, bottom, &right, &bottom);
    
    // 8. 写入输出数组 parray
    int index = atomicAdd(parray, 1);  // 原子操作获取写入位置
    float* pout = parray + 1 + index * NUM_BOX_ELEMENT;
    pout[0] = left;      // x1
    pout[1] = top;       // y1
    pout[2] = right;     // x2
    pout[3] = bottom;    // y2
    pout[4] = confidence; // 置信度
    pout[5] = label;     // 类别
    pout[6] = 1;         // keep_flag (1=保留, 0=被NMS抑制)
}
```

**关键点**:
- **并行处理**: 每个 GPU 线程处理一个 anchor，8400 个 anchor 并行解码
- **坐标变换**: 从网络输入坐标系 (640x640) 映射回原图坐标系 (1920x1080)
- **输出格式**: `parray[0]` 存储框数量，后面是每个框的 `NUM_BOX_ELEMENT=15` 个 float

### 步骤 5: NMS 去重 (`fast_nms_kernel`)

**位置**: `yolo.cu:221-249`

**作用**: 去除重叠的检测框，保留置信度最高的

```cpp
__global__ void fast_nms_kernel(float* bboxes, ...)
{
    int position = blockDim.x * blockIdx.x + threadIdx.x;
    int count = min((int)*bboxes, MAX_IMAGE_BOXES);  // 当前框总数
    if (position >= count) return;
    
    float* pcurrent = bboxes + 1 + position * NUM_BOX_ELEMENT;
    
    // 遍历所有框，找同类别且 IoU 高的框
    for (int i = 0; i < count; ++i) {
        float* pitem = bboxes + 1 + i * NUM_BOX_ELEMENT;
        
        // 跳过自己和不同类别
        if (i == position || pcurrent[5] != pitem[5]) continue;
        
        // 如果其他框置信度 >= 当前框
        if (pitem[4] >= pcurrent[4]) {
            // 计算 IoU
            float iou = box_iou(
                pcurrent[0], pcurrent[1], pcurrent[2], pcurrent[3],  // 当前框
                pitem[0], pitem[1], pitem[2], pitem[3]                // 其他框
            );
            
            // IoU 超过阈值，抑制当前框
            if (iou > threshold) {
                pcurrent[6] = 0;  // keep_flag = 0 (被抑制)
                return;
            }
        }
    }
}
```

**IoU 计算** (`box_iou`):
```cpp
float box_iou(float aleft, float atop, float aright, float abottom, ...)
{
    // 计算交集区域
    float cleft = max(aleft, bleft);
    float ctop = max(atop, btop);
    float cright = min(aright, bright);
    float cbottom = min(abottom, bbottom);
    
    float c_area = max(cright - cleft, 0.0f) * max(cbottom - ctop, 0.0f);
    
    // 计算并集
    float a_area = (aright - aleft) * (abottom - atop);
    float b_area = (bright - bleft) * (bbottom - btop);
    
    return c_area / (a_area + b_area - c_area);  // IoU = 交集 / 并集
}
```

**关键点**:
- **按类别分组**: 只对同类别框做 NMS
- **保留高置信度**: 如果两个框重叠，保留置信度更高的
- **IoU 阈值**: 通常 0.5-0.6，超过则抑制

### 步骤 6: 结果解析 (`forwards` 函数后半部分)

**位置**: `yolo.cu:720-775`

**作用**: 从 GPU 拷贝结果到 CPU，解析为 `BoxArray` 结构

```cpp
// 1. 拷贝 GPU 结果到 CPU
checkRuntime(cudaMemcpyAsync(
    output_boxarray_.cpu(),      // CPU 目标
    output_boxarray_.gpu(),      // GPU 源
    output_boxarray_.gpu_bytes(),
    cudaMemcpyDeviceToHost, stream
));
cudaStreamSynchronize(stream);   // 等待拷贝完成

// 2. 解析每张图片的结果
for (int ib = 0; ib < num_image; ++ib) {
    float* parray = output_boxarray_.cpu() + 
                    ib * (32 + MAX_IMAGE_BOXES * NUM_BOX_ELEMENT);
    
    int count = min(MAX_IMAGE_BOXES, (int)*parray);  // 框数量
    BoxArray& output = arrout[ib];
    
    // 3. 遍历每个框
    for (int i = 0; i < count; ++i) {
        float* pbox = parray + 1 + i * NUM_BOX_ELEMENT;
        
        // 解析框信息
        float left = pbox[0];
        float top = pbox[1];
        float right = pbox[2];
        float bottom = pbox[3];
        float confidence = pbox[4];
        int label = pbox[5];
        int keepflag = pbox[6];  // 1=保留, 0=被NMS抑制
        
        // 4. 只保留 keepflag=1 的框
        if (keepflag == 1) {
            Box box(left, top, right, bottom, confidence, label);
            output.emplace_back(box);
        }
    }
}

return arrout;  // 返回每张图片的检测结果
```

## 数据流图

```
原图 (1920x1080, BGR, uint8)
    ↓ [preprocess]
网络输入 (640x640, RGB, float, 归一化)
    ↓ [TensorRT forward]
bbox 特征图 (batch, 8400, 84)
    ↓ [decode_kernel_common]
候选框列表 (原图坐标, 置信度, 类别)
    ↓ [fast_nms_kernel]
去重后的框列表 (keep_flag=1)
    ↓ [CPU 解析]
BoxArray (C++ 结构体)
```

---

## 关键数据结构

### `parray` 布局 (GPU 内存)

```
parray[0]                    : 框数量 (int)
parray[1..15]                : 第 0 个框 [x1, y1, x2, y2, conf, label, keep, ...]
parray[16..30]               : 第 1 个框
...
parray[1 + i*15 .. 15 + i*15]: 第 i 个框
```

### `Box` 结构 (CPU)

```cpp
struct Box {
    float left, top, right, bottom;  // 原图坐标
    float confidence;                // 置信度
    int class_label;                 // 类别ID
    std::vector<float> points;       // 关键点 (V5Face)
    shared_ptr<InstanceSegmentMap> seg;  // 分割mask (V8Seg)
};
```

---

## 性能优化点

1. **异步拷贝**: 使用 `cudaMemcpyAsync` 和 CUDA stream，避免阻塞
2. **并行解码**: 8400 个 anchor 在 GPU 上并行处理
3. **原子操作**: `atomicAdd` 实现无锁的框计数
4. **内存复用**: `preprocess_buffers_` 和 `box_segment_cache_` 复用显存

## 不同模型类型的差异

| 模型类型 | 输出格式 | 类别数计算 |
|---------|---------|-----------|
| YOLOv5/V3/V7 | `[cx, cy, w, h, obj, cls0..clsN]` | `output_dim - 5` |
| YOLOv8 | `[cx, cy, w, h, cls0..clsN]` | `output_dim - 4` |
| YOLOv8Seg | bbox + mask head | `output_dim - 4 - mask_dim` |
| YOLOv5Face | `[cx, cy, w, h, obj, kpt0..kpt7, cls0..clsN]` | `output_dim - 5 - 8` |
